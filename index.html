Protection d'infrastructure - Pare-feu nftables & IPS Suricata
2025 - 2026 Projet académique (BUT3) Cybersécurité défensive
Contexte & objectif

Dans le cadre du BUT3 Informatique (parcours alternant), ce projet consistait à concevoir, déployer et tester une infrastructure réseau réaliste protégée par un pare-feu nftables et un IPS Suricata. L'objectif : garantir l'isolation des zones, le filtrage stateful du trafic et la détection/blocage d'attaques en temps réel, le tout en dual-stack IPv4/IPv6.

table inet filter {
  chain forward {
    type filter hook forward priority 0; policy drop;
    queue flags bypass to 0
    ct state established,related accept
    ct state invalid drop
    iifname "eth1" oifname "eth2" tcp dport 80 accept
    iifname "eth1" oifname "eth2" udp dport 53 accept
  }
}
table ip nat {
  chain postrouting {
    ip saddr 10.0.0.0/24 oifname "eth2" masquerade
    ip saddr 10.0.1.0/24 oifname "eth1" masquerade
  }
}
drop dns any any -> any any (
  msg:"DNS query for malicious.com blocked";
  dns.query; content:"malicious.com"; nocase;
  sid:1000001; rev:1;
)
alert icmp any any -> any any (
  msg:"ICMP Ping Flood detected";
  itype:8;
  detection_filter:track by_src, count 10, seconds 1;
  sid:1000002; rev:1;
)
alert tcp any any -> any 22 (
  msg:"SSH Brute Force detected";
  flags:S;
  detection_filter:track by_src, count 5, seconds 1;
  sid:1000003; rev:1;
)

Infrastructure Réseau Sécurisée
Fév - Avr 2025 Projet d'équipe 3 mois
Contexte & objectif

Dans le cadre du BUT Informatique (IUT2 Grenoble), notre équipe avait pour mission de concevoir, déployer et sécuriser une infrastructure réseau virtuelle complète simulant le réseau d'une organisation réelle.

Architecture mise en place
  • Segmentation réseau via routeurs virtuels et pare-feu
  • Serveur DHCP pour l'attribution automatique des adresses IP
  • Serveur DNS interne avec zones de résolution directe et inverse
  • Serveur Web sécurisé (HTTPS avec certificat autosigné)
  • Annuaire LDAP pour la gestion centralisée des utilisateurs
  • Serveur CAS (Central Authentication Service) pour l'authentification unique (SSO)
  • Intégration PAM pour l'authentification locale sur les machines clientes
Mon rôle

Principalement en charge des services d'authentification : OpenLDAP, PAM sur les machines clientes Linux, et déploiement du serveur CAS. Contribution à la virtualisation du réseau (Proxmox/KVM) et à la rédaction de la documentation technique.
